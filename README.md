# Калькулятор эффективной дозы

Веб-версия (PWA) Android-приложения **My_Calc** — расчёт эффективной дозы у взрослых пациентов при интервенционных исследованиях.

**E [мЗв] = Total DAP [Гр·см²] × Kd [мЗв/(Гр·см²)]**

Коэффициенты Kd — МУ 2.6.1.2944-11 в редакции МУ 2.6.1.3584-19, приложение 3 (табл. 3.1, 3.3–3.6).

## Возможности

- Области: сосуды сердца, сосуды головного мозга, брюшная полость, малый таз, сосуды нижних конечностей; напряжение 60–110 кВ (по таблицам МУ).
- Total DAP в 8 единицах (Gy/cGy/mGy/μGy · cm²/m²).
- История расчётов (сутки / неделя, выбор столбцов, очистка).
- Настраиваемый раскрывающийся список «Услуги и КСГ» (до 50 строк, вкл/выкл, перетаскивание).
- Новый и прежний вид главного экрана.
- Работает офлайн, устанавливается на телефон как приложение.

Все данные хранятся только в браузере устройства (localStorage), на сервер ничего не отправляется.

## Установка на телефон

- **Android (Chrome):** меню ⋮ → «Установить приложение» / «Добавить на главный экран».
- **iPhone (Safari):** «Поделиться» → «На экран „Домой“».

## Публикация на GitHub Pages

1. Загрузите файлы этой папки в корень репозитория.
2. Settings → Pages → Source: *Deploy from a branch*, Branch: `main`, папка `/ (root)`.
3. Через 1–2 минуты сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

После изменения файлов увеличьте номер версии `CACHE_NAME` в `sw.js`, чтобы у пользователей обновился кэш.
